Importante

Este script está pensado para ejecutarse en SQL Server Management Studio (SSMS).

Si se ejecuta en otra computadora o instancia de SQL Server:

Verificar que SQL Server esté instalado y funcionando.
Ejecutar el archivo BD_Fexi2.sql desde SQL Server Management Studio.
Si se modifica la ubicación o configuración de la instancia de SQL Server, no es necesario cambiar las tablas ni las relaciones del script.
No ejecutar el script sobre una base BD_Fexi2 que ya contenga las tablas, ya que puede indicar que los objetos ya existen.

El script incluye la creación de las tablas, relaciones y datos iniciales.
